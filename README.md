# SpendDNA – Personal Expense Analysis

## Project Overview

SpendDNA is a personal expense analysis mini project
developed as part of the Unlox Academy internship.

The project focuses on analyzing financial transaction
data using Python, Pandas, and data visualization.

It helps identify spending patterns, categorize
expenses, and understand financial habits.

## Project Objectives

- Analyze personal financial transactions.
- Identify spending patterns and trends.
- Categorize expenses.
- Calculate total spending.
- Identify major expense categories.
- Generate useful financial insights.
- Improve data analysis skills using Python.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- CSV Dataset
- GitHub

## Dataset

The project uses transaction data containing
information such as:

- Transaction date
- Transaction amount
- Expense category
- Transaction description

The dataset is analyzed to understand spending
behavior and identify expense patterns.

## Project Implementation

### Step 1: Data Collection
Import the transaction dataset in CSV format.

### Step 2: Data Loading
Load the dataset using Pandas.

### Step 3: Data Cleaning
Check missing values, duplicates, and data types.

### Step 4: Data Analysis
Analyze transaction amounts and expense categories.

### Step 5: Data Visualization
Generate charts to understand spending patterns.

### Step 6: Result Analysis
Interpret the results and identify financial trends.

## Project Features

- Transaction data analysis
- Expense categorization
- Spending pattern identification
- Category-wise expense analysis
- Data visualization
- Financial insights

1. Download the project files from GitHub.
